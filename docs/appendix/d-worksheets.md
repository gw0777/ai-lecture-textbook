## D-1. 업무 분해 시트

내 직무(또는 신입이 맡을 직무)를 업무 단위로 쪼개고, 기업이 쓰는 세 가지 질문으로 판정합니다.
**세 질문 모두 "예"인 업무**는 AI로 넘어가기 쉽고, 하나라도 "아니오"인 업무는 사람이 지킬 자리입니다.

| 업무 | 반복적인가? | 정형화됐는가? | 결과를 검증하기 쉬운가? | 판정 (AI / 사람 / 함께) | 사람이 지켜야 할 이유 |
|---|---|---|---|---|---|
|  |  |  |  |  |  |
|  |  |  |  |  |  |
|  |  |  |  |  |  |
|  |  |  |  |  |  |
|  |  |  |  |  |  |

> 🗣 **토론** "이 업무의 결과를 누가, 어떻게 검증하는가?"

## D-4. 창작자 4사분면 자기진단 (확장판)

> 💡 [10장 실습 1](../part3/10-irreplaceable-creator.md)은 **최근 결과물 3개**로 점을 찍어 보는 **간단판**입니다. 이 확장판은 **나의 평소 습관**을 묻습니다. 수업에서는 간단판을 먼저 하고, 시간이 있으면 확장판으로 비교해 보세요. 두 결과가 다르면, "평소 습관"과 "실제 결과물" 사이에 어떤 차이가 있는지가 좋은 성찰 거리입니다.

가로축은 **인간의 경험 및 통찰력**, 세로축은 **AI 의존도 및 활용도** 입니다. 각 문항에 1(전혀 아니다)~5(매우 그렇다)로 답하세요.

| 문항 | 점수 |
|---|---|
| ① 나는 내 분야에서 직접 겪은 장면·사례를 3개 이상 바로 말할 수 있다 |  |
| ② 나는 결과물을 만들기 전에 내 생각을 글이나 메모로 먼저 정리한다 |  |
| ③ 나는 AI가 만든 초안에서 틀린 곳·평범한 곳을 찾아 고칠 수 있다 |  |
| **경험·통찰력 합계 (①+②+③)** |  |
| ④ 나는 일주일에 3번 이상 업무·공부에 AI를 쓴다 |  |
| ⑤ 나는 같은 일을 AI와 함께 할 때 걸리는 시간을 줄여 본 경험이 있다 |  |
| ⑥ 나는 목적에 따라 다른 AI 도구를 골라 쓸 수 있다 |  |
| **AI 활용도 합계 (④+⑤+⑥)** |  |

| | 경험·통찰력 3~9점 | 경험·통찰력 10~15점 |
|---|---|---|
| **AI 활용도 10~15점** | Q4 딸깍 창작자 → 경험을 더하세요 | ⭐ Q1 경험 창작자 |
| **AI 활용도 3~9점** | Q3 도태된 작업자 → 둘 다 시작하세요 | Q2 전통적 장인 → AI로 속도를 더하세요 |

## D-9. 모델 비교표

두 모델에 **같은 요청을 그대로** 넣고 비교합니다. 한쪽에만 조건을 더하면 비교가 되지 않습니다.

| 기준 | 모델 A: ______ | 모델 B: ______ |
|---|---|---|
| 요구한 시간·인원·준비물 준수 | 충족 / 미충족 | 충족 / 미충족 |
| 대상별 방법이 구체적임 | 충족 / 미충족 | 충족 / 미충족 |
| 바로 쓸 문장(지시문·안내문) 제공 | 충족 / 미충족 | 충족 / 미충족 |
| 제공하지 않은 사실을 만들지 않음 | 충족 / 미충족 | 충족 / 미충족 |
| 내가 수정해야 할 분량 | 적음 / 보통 / 많음 | 적음 / 보통 / 많음 |

> ✅ **확인** 좋은 모델은 **수정 시간이 적고, 근거와 불확실성을 잘 구분하는 모델**입니다. 모델이 스스로 매긴 점수는 증거가 아닙니다.
