## 3. AI 시대의 일과 경영

| 용어 | 쉬운 뜻 | 나오는 곳 |
|---|---|---|
| 입구 쇼크 (Entry Shock) | AI가 신입의 기초 업무를 흡수하면서 노동시장의 '입구'가 좁아지거나 모양이 바뀌는 현상 | [01장](../part1/01-entry-shock.md) |
| 채용 절벽 | 대기업 정규직 신입 공고가 급격히 줄어드는 현상 | [01장](../part1/01-entry-shock.md) |
| 유령 공고 | 게시만 하고 실제 채용은 거의 진행하지 않는 공고 | [01장](../part1/01-entry-shock.md) |
| AI 문해력 | AI를 업무에 적용하고, 그 결과를 비판적으로 검증하는 능력. 채용의 '입장권' | [01장](../part1/01-entry-shock.md) |
| 비용 비대칭 | 신입을 키우는 비용과 AI를 도입하는 비용의 격차 | [01장](../part1/01-entry-shock.md) |
| 온보딩 | 새로 들어온 사람이 조직에 적응해 제 몫을 하기까지의 과정 | [01장](../part1/01-entry-shock.md) |
| 피라미드 → 다이아몬드 | 넓은 신입층이 받치던 조직이 중간·시니어 중심으로 바뀌는 인력 구조 변화 | [01장](../part1/01-entry-shock.md) |
| 구조적 레버리지 | 세상이 돌아가는 '숨겨진 설계도'를 먼저 읽고, 작은 힘으로 큰 결과가 나는 지점에 힘을 쓰는 것 | [02장](../part1/02-structural-leverage.md) |
| 캐시플로우 (현금 흐름) | 실제로 회사에 돈이 들어오고 나가는 흐름 | [02장](../part1/02-structural-leverage.md) |
| 흑자부도 | 장부상으로는 이익이 났는데 당장 현금이 없어 회사가 쓰러지는 상황 | [02장](../part1/02-structural-leverage.md) |
| 조직건강 | 조직이 꾸준히 성장하고 변화에 적응할 수 있는 능력 (소통·참여·몰입·리더십 등) | [19장](../part5/19-health-leadership.md) |

| 측정 가능성 | 성공했는지 예/아니오로 판정할 수 있는 정도 | [14장](../part4/14-ai-self-check.md) |

| USE → MAKE → FAIL → MODIFY → MAKE AGAIN | 이 교재의 학습 순환: 써 보고, 만들고, 실패하고, 고치고, 다시 만든다 | [20장](../finale/20-final-mission.md) |
